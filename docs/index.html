Give the agent
the books.
Not the keys.

Selektos is a native macOS workspace for PostgreSQL and Cloudflare D1 that is also a local MCP server. Your coding agent reads your real databases through it: schemas, rows, answers. Every password stays in the macOS Keychain, and read-only is the setting you never have to remember to switch on.

The booksFolio 02

An auditor may read the books.
An auditor may not post.

The same statement, offered twice. You are the bookkeeper and it runs. Your agent is the auditor, and three separate layers have to agree before anything reaches Postgres. The first of them settles it, so nothing is ever opened to be rolled back.

By you, in the app

update invoices set status = 'paid'
where id = '8f2a41c9';
  1. Layer 1 · validator

    Not applied. The app is not an MCP client, and you are not an agent.

  2. Layer 2 · transaction

    Your own session, opened with your credentials, reading and writing

  3. Layer 3 · tool class

    Not applied. Nothing here is reached through a published tool.

update 1 · posted to the table

By the agent, over MCP

update invoices set status = 'paid'
where id = '8f2a41c9';
  1. Layer 1 · validator

    Statement classified as mutating and rejected before execution

  2. Layer 2 · transaction

    Had it passed, execution runs under default_transaction_read_only

  3. Layer 3 · tool class

    Discovery, describe and preview stay read-only whatever the settings say

refused · nothing reached the database

RefusedNo posting rights

A worked example: the statement and the row id are invented, the three enforcement layers are the real ones.

Read-only access is on by default. Turning it off hands the agent your rights, a switch you throw on purpose, in Settings → MCP Server, knowing exactly what it means.

Posting rightsFolio 03

Schedule of exposed tools

Every saved connection publishes four tools of its own, named for it, plus one directory tool for the workspace. Nothing else is reachable.

EntryToolWhat it returnsRights
001list_connections Connection metadata and the exact tool names published for each one Read
002list_tables_<conn> Accessible tables and views, without reading a single row Read · always
003describe_table_<conn> Column, type, nullability, default and primary-key metadata Read · always
004preview_table_<conn> A safely quoted table name and a capped row preview Read · always
005query_<conn> One SQL statement you named, with an optional row limit. It can write only if you turn read-only off yourself. Read by default

PostgreSQL tools take optional database and schema arguments. Passwords are never part of any tool's metadata.

Where the keys are kept

EntryHeld itemWhere it livesCustody
001PostgreSQL passwords macOS Keychain. Read to open a connection, never placed in a tool response, a log line or a config file. You
002Cloudflare tokens Held entirely by your own authenticated Wrangler CLI. Selektos shells out to it and never reads a token. Wrangler
003Agent transport Local stdio, started by your MCP client on your machine. No listener, no broker and no account. Your machine
004Workspace state A plain JSON file under Application Support that you can read, move or delete yourself. You

Posting instructions

Five steps from an empty checkout to an agent answering questions about your own data.

  1. Clone it and run it

    Swift Package Manager builds and launches the app. Xcode works too: open Package.swift and pick the Selektos scheme.

  2. Add a connection

    PostgreSQL takes a host, a database and a password that goes straight to the Keychain. For Cloudflare D1, run wrangler login first, then press Discover.

  3. Open Settings → MCP Server

    Enable MCP access, leave read-only on, and set the row cap each tool call is allowed to return.

  4. Paste the configuration

    Selektos writes the snippet for you using whatever executable is running, so the path matches your own checkout. Drop it into your MCP client.

  5. Restart the client

    It re-reads the tool list on start, so restart it after changing access, limits or connections.

mcp.jsonyour MCP client
{
  "mcpServers": {
    "selektos": {
      "command": "/Users/you/selektos/.build/debug/Selektos",
      "args": ["--mcp-server"]
    }
  }
}
