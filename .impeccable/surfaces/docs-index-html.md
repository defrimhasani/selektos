# Surface brief — docs/index.html (Selektos site)

## Scope

The project's GitHub Pages landing page, served statically from `docs/` with no build step.
Visitor mode: **Persuade**.

- **Audience:** macOS developers who work with PostgreSQL daily and want a native client. They
  evaluate in about ninety seconds from a repo link.
- **Job:** decide whether Selektos is worth building from source today.
- **Action:** `git clone` → `swift run Selektos`. **There is no published release**; a releases CTA
  would land on an empty page. Secondary action: read the source.
- **Proof available:** the app itself, the MCP tool table, the three-layer read-only enforcement, the
  app icon. **No** testimonials, users, stars, press, benchmarks, or download counts exist.
- **Constraints:** static HTML/CSS only, no bundler, no server. Name Selektos, publisher Pluto Labs.
  No license claim. macOS 15+.

## Direction contract

**THESIS.** Read-only is not a checkbox, it is an auditor's copy of the books: full sight, no posting
rights. The page refuses the arrangement this category always ships, and that this site currently is
— near-black ground, violet bloom, the app screenshot floating in glass window chrome, three
same-size feature cards.

**OWN-WORLD.** Greenbar continuous-feed paper over a double-entry ledger. Paper `#F1EFE3`; alternating
bar green `#B9D0B2`; deep ledger green `#1B3A2B` for solid fields; letterpress black `#14160F` for
hairline and heavy rules; audit red `#A02A1C` for stamps and refusals only. Sprocket-hole margins run
the full page height. Structure is ruled columns edge to edge: no cards, no rounded corners, no
gradients, no shadow-floated panels. Condensed institutional caps knock white out of green fields;
line-printer mono sets every figure, identifier, and command; numerals are tabular everywhere.

**STORY.** The visitor learns Selektos is a native Mac database workspace that is also a local MCP
server; believes the read-only boundary is structural rather than promised, because the page shows
the same statement being posted, read, and refused side by side; and runs two commands to build it.

**FIRST VIEWPORT.** One continuous greenbar sheet, edge to edge, sprocket margins on both sides. A
full-measure solid ledger-green band carries the headline knocked out in condensed caps. Directly
beneath, the first posted ledger line *is* the primary action: a ruled entry whose description column
reads `git clone …` / `swift run Selektos`, with a real copy control in the amount column. To the
right of the fold, five MCP entries post as ruled ledger lines under running column heads, and a
red `READ ONLY — NO POSTING RIGHTS` stamp strikes across them at an angle, overprinting the rules the
way a rubber stamp does. No eyebrow, no glow, no floating window.

**FORM.** The Auditor's Ledger — candidate 7 of the ordered grounded list, the roll's assignment;
seed key `e1a572ea`. Raised by the hands it beat: *states print themselves* as dated ledger entries
rather than chrome badges (from Phosphor Terminal, declined); *arrival is staged* through thresholds
that tighten rather than equal-weight sections (from Deco Cinema Lobby, declined); *states are shown
in synchronized parallel, never described* (from Rain-Night Cityscape, declined).

**FINISH.** unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Memorable moment

The refusal ledger: one real `UPDATE` statement posted through the MCP path, its three enforcement
layers printed as consecutive ledger entries, the last one stamped in audit red. The enforcement is
watched, not claimed.
